# Smart Campus Navigation and Route Optimization System Using Python

## Features
- Weighted campus graph using NetworkX
- Manual Dijkstra shortest-path implementation
- Walking-time estimate
- Alternative route when a connection is blocked
- Route and campus visualization with Matplotlib
- SQLite route-search history

## Run in VS Code (Windows)
1. Install Python 3.10 or newer.
2. Extract the ZIP and open this folder in VS Code.
3. Open Terminal and run: `python -m pip install -r requirements.txt`
4. Run: `python main.py`

Example: choose option 1, enter `Main Gate`, then `Library`.

## Important
The locations and distances are illustrative sample data, not official campus measurements. Replace them with verified measurements or explicitly describe them as sample data in your report. Walking-time estimates assume 80 metres per minute.
